1. 项目背景

代谢组交互分析平台需要同时满足三类用户诉求：进入平台后能直接查看原始生信交付结果；能在图表页面直接修改图形样式；能基于新的数据、样本分组、差异比较组和参数在模块内生成新结果，而不必所有操作都走完整重分析流程。

现有 UI 原型已经形成较完整的页面框架，包括分析方案管理、数据集管理、总体样本 PCA、差异计算、差异下游模块、差异代谢物富集分析、关注物质富集分析和一键重分析。本版 PRD 在此基础上重点补充模块数据来源和逻辑规则，让研发和生信能明确每个模块到底消费什么输入、何时需要重新计算、何时只是展示或筛选。

核心结论：数据决定分析哪些代谢物；分析方案决定哪些样本参与和如何分组；差异比较组决定谁和谁比较；差异分析结果承载一次比较的整体结果；filter 承载基于阈值筛选出的差异代谢物集合；模块结果必须绑定其输入来源和参数。

2. 产品目标与非目标

2.1 产品目标

  • 用户可以默认查看原始生信分析结果。
  • 用户可以通过分析方案管理维护样本启用状态、分组关系和差异比较组。
  • 用户可以通过数据集管理维护代谢物集合，包括系统数据、筛选数据、集合运算数据、差异 filter 数据和用户上传数据。
  • 用户可以在总体 PCA、差异计算、差异下游分析、富集分析等模块中直接提交当前模块分析。
  • 差异分析板块以“差异计算 / 差异分析结果”为主入口，生成整体结果和 filter。
  • 差异下游模块统一基于差异分析结果 + filter，而不是重新选择数据 + 分组方案 + 比较组。
  • 差异代谢物富集分析作为差异下游模块，仍放在差异分析中。
  • 关注物质富集分析作为扩展分析模块，不要求输入来自差异分析。
  • 每个模块必须说明数据来源、分析方案、比较组、filter、参数和结果来源之间的关系。
  • 所有新生成结果都应作为新结果版本存在，不覆盖原始结果。

2.2 非目标

  • 不把所有修改都引导到一键重分析。
  • 不把差异富集分析和关注物质富集分析合并成一个页面。
  • 不让差异下游模块重新从数据、分组方案、比较组和阈值开始配置。
  • 不允许修改原样本名作为底层数据唯一键。
  • 不让保存分析方案自动更新所有已有结果。
  • 不把样式设置和统计参数混在一个面板。
  • 不在页面上暴露研发建模术语，如 Contrast Result、Diff Set。

3. 设计原则

结果可追溯

每个模块结果都必须能追溯到数据、分析方案、差异比较组、filter、参数、来源和生成时间。

输入变化不自动覆盖结果

用户修改数据、分析方案、比较组或参数后，当前展示结果不自动更新，应提示“当前展示结果与当前选择不一致”。

差异计算是差异分析主入口

差异计算产生一次差异分析结果，其中包含筛选前整体图表和基于阈值的 filter。

差异下游只消费 filter

差异热图、雷达图、条形图、小提琴图、相关性、Kmeans 和差异富集都基于 filter 继续分析。

差异富集与关注富集分离

差异富集属于差异分析；关注物质富集属于扩展分析，支持普通数据集或用户上传物质列表。

一键重分析是完整报告生成器

一键重分析用于生成一整套新版结果和报告，不承担单模块分析入口职责。

4. 核心概念定义

概念 面向用户的定义 示例 关键规则
数据 参与当前分析的代谢物集合。 全部代谢物_原始、Lipid 类代谢物、差异 filter 数据 决定“分析哪些代谢物”。
分析方案 样本启用状态、样本分组关系和差异比较组的组合。 默认方案、自定义方案_v2、AB合并方案 决定“哪些样本参与、怎么分组、哪些组比较”。
原样本名 生信交付和底层数据使用的样本唯一键。 A1、A2、B1 不可修改。
样本显示名 图表和表格中展示给用户的样本名称。 Control_1、Treatment_1 只影响展示，不影响统计结果。
组显示名 图例、标题、表格中展示的分组名称。 Control、Treatment 只改显示名不影响统计；合并分组会影响统计。
差异比较组 定义哪两个组进行差异分析以及方向。 B vs A、C vs A B vs A 表示 A 为对照，B 为处理，FC = B 均值 / A 均值。
差异分析结果 一次差异计算生成的整体结果。 B_vs_A_差异分析_2026-05-14 包含 PCA、OPLS-DA、火山图、差异统计、差异总表和 filter。
filter 基于差异阈值筛选出的差异代谢物集合。 FC≥2，p-value<0.05，VIP≥1 差异下游模块和差异富集分析的主要输入。
模块结果 某个模块基于指定输入和参数生成的结果。 PCA任务、差异热图任务、KEGG富集任务 不自动覆盖原始结果，应作为新版本保存。

5. 核心数据对象与关系

项目 Project ├─ 原始生信结果 ├─ 数据 Data / Dataset：决定分析哪些代谢物 ├─ 分析方案 Analysis Scheme：决定哪些样本参与、样本如何分组、有哪些比较组 ├─ 差异比较组 Comparison：决定谁 vs 谁，以及方向 ├─ 差异分析结果 Differential Result：一次差异计算的整体产物 │ ├─ 筛选前整体结果：PCA / OPLS-DA / 火山图 / 差异统计 / 差异总表 │ └─ 差异筛选结果 filter：All / Up / Down 差异代谢物 ├─ 模块结果 Module Result：热图、雷达、条形图、富集等单模块结果 └─ 样式 Style：颜色、字体、标题、图例、导出等展示配置

5.1 对象之间的依赖关系

对象 上游依赖 下游影响 变化后是否需要重新生成结果
数据 原始矩阵、筛选数据、集合运算、用户上传 PCA、差异计算、富集、关注物质分析 是，影响所有使用该数据的分析。
分析方案 样本启用状态、样本分组、比较组 总体 PCA、差异计算、差异下游 是，但不自动更新已有结果。
差异比较组 分析方案中的有效分组 差异分析结果、filter、差异下游 是，比较组改变后需重新做差异计算。
差异分析结果 数据 + 分析方案 + 比较组 + 差异参数 火山图、差异总表、filter、差异下游模块 输入或参数变化后需重新生成。
filter 差异分析结果 + 阈值 差异热图、雷达、条形图、富集、Kmeans 等 阈值变化后需生成新的 filter 或更新当前 filter。
样式 用户设置 图形展示 否，只影响展示。

7. 全局逻辑规则

7.1 数据变化规则

用户操作 本质 影响范围 产品规则
切换数据 代谢物集合变化 影响 PCA、差异计算、富集、热图等所有基于该数据的结果 当前展示结果应标记为与当前选择不一致，用户需提交当前模块分析。
保存筛选结果为新数据 生成派生数据集 可作为后续模块输入 不覆盖原数据，进入数据集管理列表。
集合运算生成新数据 基于多个数据集生成新集合 可用于 PCA、富集、差异计算等 保存为新数据集，记录来源数据集和运算方式。
用户上传数据 新增输入数据 可用于关注物质富集等扩展分析 需校验 ID 类型和必要字段。

7.2 样本与分组变化规则

用户操作 是否影响统计结果 是否需要重新分析 说明
只改样本显示名 否 否 只影响图中标签和表格显示。
只改组显示名 否 否 只影响图例、表头、比较组展示名。
修改原样本名 高风险 禁止 原样本名是底层数据唯一键，不允许编辑。
样本不参与当前分析 是 是 改变样本集合，会影响均值、方差、PCA 坐标、FC、p-value 等。
样本跨组移动 是 是 改变分组关系，会影响差异分析和监督模型。
分组合并 是 是 可能导致原有比较组失效。
所有样本合并为一个组 是 差异类模块不可计算 差异分析至少需要两个有效分组。

7.3 差异比较组规则

规则 说明
比较组必须来自当前分析方案中的有效分组 如果分组被删除、合并或没有有效样本，则相关比较组失效。
B vs A 必须明确方向 A 是对照组，B 是处理组，FC = B 均值 / A 均值。
比较方向反转视为新比较 A vs B 与 B vs A 的 logFC 方向、上下调解释不同，不应简单改名。
新增比较组需要重新计算差异结果 不能使用其他比较组的差异结果直接替代。
当前方案少于两个有效分组时，差异比较组不可运行 页面应提示前往分析方案管理调整分组。

7.4 filter 规则

规则 说明
filter 必须来源于某个差异分析结果 filter 不是独立凭空生成的数据，应记录来源差异分析结果。
filter 由阈值生成 阈值可包括 FC、p-value、FDR、VIP 等。
filter 可以包含方向信息 若包含方向，可拆分 All / Up / Down；若无方向，只能作为单一集合使用。
火山图阈值调整默认不重新计算统计值 仅基于已有差异分析结果重新分类和着色。
保存 filter 后可作为下游输入 可用于差异热图、条形图、富集、Kmeans 等模块。

7.5 结果一致性规则

场景 状态 页面处理
当前选择与展示结果完全一致 与当前选择一致 正常展示结果。
用户切换数据、方案、比较组或参数，但未提交分析 当前展示结果与当前选择不一致 提示用户提交当前模块分析或继续查看旧结果。
当前组合没有已有结果 当前组合暂无结果 提供“提交当前模块分析”按钮。
当前方案不能计算 当前方案不可计算 提示具体原因，例如有效分组不足。

当前结果来源：原始结果 / 我的分析结果 / 一键重分析结果 数据：xxx 分析方案：xxx 比较组：xxx 差异分析结果：xxx，若当前模块属于差异分析 差异筛选结果 filter：xxx，若当前模块基于 filter 参数：xxx 生成时间：xxxx-xx-xx xx:xx 状态：与当前选择一致 / 当前展示结果与当前选择不一致 / 当前组合暂无结果 / 当前方案不可计算

9.2 状态示例

当前结果来源：我的分析结果 · 差异分析结果：B_vs_A_差异分析_2026-05-14 · filter：FC≥2，p-value<0.05，VIP≥1 · 差异代谢物：224 个，上调 128 个，下调 96 个 · 状态：与当前选择一致
当前展示结果与当前选择不一致。你正在查看的是旧结果。如果需要基于当前选择生成新结果，请点击“提交当前模块分析”。
当前方案仅包含 1 个有效分组，无法执行差异分析。请至少保留 2 个有效分组，并保证每个分组满足最小样本数要求。

10. 分析方案管理

分析方案管理负责维护样本参与状态、分组关系和差异比较组，是差异分析和总体样本分析的重要输入。

10.1 数据来源

输入 说明
原始样本信息 来自生信交付项目，包括原样本名、默认分组、QC 信息等。
用户编辑信息 样本显示名、是否参与分析、分组归属、组显示名、差异比较组。

10.2 页面功能

  • 样本管理：行视角，编辑样本显示名、勾选是否参与分析、修改分组归属。
  • 分组管理：列视角，查看每组成员、新增分组、删除分组、修改组显示名。
  • 差异比较组设置：基于当前有效分组定义 B vs A、C vs A 等比较组。
  • 已保存方案列表：查看、切换、重命名、删除分析方案。

10.3 逻辑规则

操作 规则
保存分析方案 只保存方案定义，不自动更新任何模块结果。
修改样本显示名 只影响展示，不影响已有统计结果。
取消样本参与分析 会改变样本集合，相关模块需要重新计算。
移动样本分组 会改变分组均值、方差和比较结果，差异分析需重新计算。
删除或合并分组 若导致比较组中某组不存在，则该比较组失效。
只剩一个有效分组 差异分析、OPLS-DA、火山图、差异富集等差异类模块不可运行。

10.4 保存提示文案

分析方案已保存。 该操作不会自动更新已有结果。 你可以在各分析模块中选择该方案并提交当前模块分析，或在一键重分析中生成完整新版报告。

11. 数据集管理

数据集管理负责维护代谢物集合，是所有模块的统一数据输入入口。

11.1 数据来源

数据类型 来源 可用于模块
系统数据 原始定量矩阵、原始差异结果等 PCA、差异计算、富集、热图等
筛选数据 用户按字段、数值、类别等筛选后保存 PCA、关注物质富集、差异计算等
集合运算数据 多个数据集交集、并集、差集、对称差 PCA、关注物质富集、下游分析
差异 filter 数据 差异分析结果或火山图筛选保存 差异热图、差异雷达、差异条形图、差异富集
用户上传数据 用户上传物质列表或矩阵 关注物质富集、扩展分析

11.2 逻辑规则

  • 数据集只定义“哪些代谢物参与分析”，不定义样本如何分组。
  • 分析方案定义“哪些样本参与分析，以及样本如何分组”。
  • 数据和分析方案共同决定模块分析的基础输入。
  • 差异 filter 数据必须保留来源差异分析结果和筛选条件。
  • 筛选数据、集合运算数据、差异 filter 数据均不覆盖系统数据。

12. 总体样本 PCA

12.1 数据来源

输入项 是否必需 说明
数据是决定使用哪些代谢物参与 PCA。
分析方案是决定哪些样本参与 PCA，以及样本分组展示。
比较组否总体 PCA 不依赖差异比较组。
filter否总体 PCA 不以差异 filter 为默认输入，除非用户主动选择某个 filter 数据作为数据集。

12.2 逻辑规则

  • 只改样本显示名：PCA 坐标不变，仅标签变化。
  • 只改组显示名：PCA 坐标不变，仅图例变化。
  • 改样本参与状态：PCA 输入样本改变，需重新计算。
  • 改数据：代谢物集合改变，需重新计算。
  • 改 log / scale 等 PCA 参数：需重新计算。
  • 切换分析方案但不提交计算时，状态条显示“当前展示结果与当前选择不一致”。

13. 差异计算 / 差异分析结果

差异计算是差异分析板块的主入口，用户在此选择数据、分析方案、比较组和差异阈值，提交后生成一次完整的差异分析结果。

13.1 数据来源

输入项 是否必需 说明
数据是决定哪些代谢物参与差异计算。
分析方案是决定哪些样本参与、样本属于哪个组。
差异比较组是决定谁和谁比较，例如 B vs A。
统计方法是例如 t-test、Wilcoxon 等。
模型方法按需例如 OPLS-DA、VIP 计算等。
差异筛选阈值是用于生成 filter，并影响火山图分类。

13.2 输出结果

输出 说明 是否基于 filter
差异分组 PCA展示比较组样本整体分布。否，基于筛选前数据。
OPLS-DA展示监督模型结果。否，基于筛选前数据或模型输入数据。
火山图所有代谢物都画点，阈值用于分类着色。否，画点数据基于筛选前全量差异结果。
差异结果统计展示 All / Up / Down 数量等。是，统计基于 filter。
差异结果总表包含全量代谢物的 FC、p-value、FDR、VIP 等。否，可在表格中筛选。
差异筛选结果 filter满足阈值的差异代谢物集合。是。

13.3 差异筛选阈值说明文案

差异筛选阈值用于生成 filter 结果，并影响火山图中上调 / 下调 / 不显著的分类；PCA、OPLS-DA 等整体差异图基于筛选前数据生成。

13.4 逻辑规则

  • 差异计算必须至少有两个有效分组。
  • 比较组中的两个组都必须有满足要求的样本数。
  • 数据、分析方案、比较组、统计方法变化后，旧差异分析结果不能视为匹配当前选择。
  • 阈值变化可以生成新的 filter，但不等于重新计算 FC、p-value、VIP。
  • 差异分析结果应进入“我的分析结果”列表，不覆盖原始结果。

样式设置上调、下调、不显著颜色，标签显示，字体，标题，导出等。

  • 火山图所有代谢物都画点。
  • 阈值只改变点的分类和颜色，不重新计算 FC、p-value、VIP。
  • 用户可以保存当前筛选为 filter。
  • 保存 filter 后，可用于差异热图、雷达图、条形图、差异富集等模块。
  • 如果切换差异分析结果，火山图应使用新差异分析结果的全量差异表。

14.3 保存 filter 成功提示

18. 一键重分析

一键重分析用于生成完整新版分析结果和报告，不作为单个模块分析入口。

18.1 数据来源

输入项 说明
数据决定完整重分析使用哪些代谢物。
分析方案决定样本参与状态和分组。
差异比较组决定要生成哪些比较结果。
差异筛选阈值决定默认 filter。
分析参数模板决定 PCA、差异分析、热图、富集等模块参数。
纳入报告模块决定新版报告包含哪些模块。

18.2 逻辑规则

  • 一键重分析生成一整套完整新版结果。
  • 一键重分析结果不覆盖原始生信结果。
  • 单模块分析结果不自动进入报告，除非被纳入一键重分析配置。
  • 一键重分析可引用已有分析方案和数据集。
  • 若分析方案不可计算，应在提交前拦截。

19. 新增数据来源、任务回显与筛选管理规则

本节用于补充各模块在“选择数据”“选择差异分析结果”“选择分析任务”“结果筛选保存”和“集合运算”上的约束。该规则优先级高于普通下拉选择逻辑，研发实现时应作为数据源过滤和校验规则。

19.1 数据结果评估的数据来源限制

数据结果评估板块用于评估原始数据或原始数据筛选子集的质量、分布和基础统计情况，因此不能选择差异结果、差异 filter、富集筛选结果或用户上传的关注物质列表。
模块 允许选择的数据 不允许选择的数据 规则说明
数据结果评估 all_sample_data；基于 all_sample_data 筛选得到的数据 差异分析结果、差异 filter 数据、富集筛选结果、用户上传关注物质列表、非 all_sample_data 来源数据 该板块只评估原始全量样本数据或其筛选子集。

19.2 差异计算的数据来源限制

差异计算需要回到原始定量矩阵层面进行组间统计，因此“选择数据”只能选择 all_sample_data 或基于 all_sample_data 筛选得到的数据。
模块 允许选择的数据 不允许选择的数据 规则说明
差异分析 - 差异计算 all_sample_data；基于 all_sample_data 筛选得到的数据 原始生信上传的差异分析结果、云平台生成的差异分析结果、差异 filter 数据、富集筛选结果、用户上传关注物质列表 差异计算输入必须是可回溯到原始定量矩阵的代谢物数据集合。

19.3 差异分析其它模块的数据来源限制

差异分析板块中除“差异计算”之外的其它模块，例如差异火山图、差异热图、差异雷达图、差异条形图、差异富集分析等，页面上的“选择数据”或“差异分析结果”应统一理解为选择某一次已有的差异分析结果。

模块范围 允许选择 不允许选择 规则说明
差异分析板块其它分析 原始生信上传的差异分析结果；云平台“差异计算”中得到的差异分析结果 all_sample_data、普通筛选数据、集合运算数据、用户上传关注物质列表、富集筛选结果 这些模块不重新发起差异计算，只消费已有差异分析结果及其 filter。

19.4 选择分析任务后的参数回显规则

任意一个模块中，当用户在结果展示部分选择了某个分析任务后，上方参数设置区域必须回显该任务当时提交时使用的数据及参数，保证用户能看清当前结果从哪里来。

模块类型 选择任务后需要回显的内容
数据结果评估 数据、分析方案，若有、图表参数、任务名称、提交时间。
总体样本 PCA 数据、分析方案、log / scale、PCA 参数、任务名称、提交时间。
差异计算 数据、分析方案、比较组、统计方法、模型方法、差异筛选阈值、任务名称、提交时间。
差异下游模块 差异分析结果、filter、当前模块参数、任务名称、提交时间。
差异代谢物富集分析 差异分析结果、filter、All / Up / Down 子集、数据库、物种、背景集、任务名称、提交时间。
关注物质富集分析 输入来源、物质 ID 类型、数据库、物种、背景集、任务名称、提交时间。
  • 回显状态下，参数区域应标识“当前为任务参数回显”。
  • 用户修改任意回显参数后，状态条变为“当前展示结果与当前选择不一致”。
  • 用户可基于回显参数点击“复制参数新建任务”或“提交当前模块分析”。
  • 参数回显不应修改历史任务本身。

19.5 结果筛选与集合运算规则

除富集分析结果筛选外，其它模块的结果筛选，或者针对原始生信上传数据的筛选，都可以保存为代谢物数据集，并参与交集、并集、差集、对称差等集合运算。

筛选来源 是否可保存 保存位置 是否可参与交集 / 并集 / 差集

19.6 富集筛选管理

富集分析的结果筛选不保存到“数据集管理”，而是保存到新增的独立板块“富集筛选管理”。富集筛选管理中的数据是富集通路或富集条目集合，不是代谢物集合，因此不能参与交集、并集、差集等集合运算。

规则 说明

富集筛选结果不能参与集合运算 不能与代谢物数据集做交集、并集、差集、对称差等运算。
富集筛选结果不能作为差异计算输入 差异计算只能选择 all_sample_data 或基于 all_sample_data 筛选的数据。
富集筛选结果用于查看和复用 可用于查看重点通路、下载富集筛选表、复制筛选条件、回到来源富集任务。

21. 验收标准

  • PRD 和原型中能清楚区分数据、分析方案、差异比较组、差异分析结果、filter、模块结果。
  • 每个核心模块均明确展示其数据来源。
  • 总体 PCA 不要求选择差异比较组。
  • 差异计算必须选择数据、分析方案和比较组。
  • 差异计算页面能说明 PCA / OPLS-DA / 火山图基于筛选前数据，filter 基于差异阈值生成。
  • 火山图能基于已有差异分析结果调整阈值并保存 filter。
  • 差异下游模块统一选择差异分析结果 + filter。
  • 差异下游模块不再从数据、分组方案、比较组和阈值重新开始配置。
  • 差异代谢物富集分析保留在差异分析下，支持 All / Up / Down。
  • 关注物质富集分析位于扩展分析下，不要求差异分析结果作为输入。
  • 保存分析方案不自动更新已有结果。
  • 当前选择变化后，结果状态条能提示当前展示结果与当前选择不一致。
  • 原始生信结果不会被在线模块结果或一键重分析结果覆盖。
  • 样式设置只影响展示，不和统计参数混淆。
  • 异常场景均有明确提示，包括有效分组不足、filter 为空、filter 无方向、比较组失效等。
  • 数据结果评估的“选择数据”只能展示 all_sample_data 或基于 all_sample_data 筛选的数据。
  • 差异计算的“选择数据”只能展示 all_sample_data 或基于 all_sample_data 筛选的数据。
  • 差异分析其它模块中的“差异分析结果”只能选择原始生信上传的差异结果或云平台差异计算结果。
  • 任意模块选择历史分析任务后，上方参数设置区能回显该任务当时提交的数据和参数。
  • 除富集分析结果筛选外，其它模块结果筛选和原始生信上传数据筛选可保存为数据集并参与集合运算。
  • 富集分析结果筛选保存到独立的“富集筛选管理”，且不能参与集合运算。
